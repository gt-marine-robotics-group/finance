# Chrome Extensions for MRG Finance

You can place Chrome extensions in this directory to automatically load them into automated browser sessions:

- **Share-A-Cart (`.crx` or unpacked directory)**:
  - Download the `.crx` from the Chrome Web Store or export your unpacked extension folder here as `share-a-cart/`.
  - When `mrg-finance purchase` runs, it will automatically load the extension into Chrome and prompt you to create your cart link.

See [docs/user/CLI_GUIDE.md](../docs/user/CLI_GUIDE.md) for full CLI automation details.
